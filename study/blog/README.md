# Blog

学习过程中写的博客文章放这里。与 `study/` 的笔记不同:笔记是给自己看的走读记录,博客是**整理后对外可发布**的文章。

## 约定

- 文件名:`YYYY-MM-DD-<slug>.md`(如 `2026-08-22-agent-harness-lanes.md`)
- 一文一个主题,建议对应学习路线中的一个模块或一个跨模块的洞察
- 写完某个模块的「检查点」能全答上时,是动笔写该主题的好时机

## 文章模板

```markdown
# <标题>

> 关联模块:[../0X-xxx.md](../0X-xxx.md) | 日期:YYYY-MM-DD

## 问题 / 背景
（这篇文章解决什么问题,为什么值得写）

## 核心思路
（按「问题 → 具体例子/走读 → 解法 → 为什么必须这样」组织,见 AGENTS.md 的行文风格要求)

## 代码定位
（涉及的关键文件与行号,方便读者对照源码)

## 总结
（一段话收束)
```
